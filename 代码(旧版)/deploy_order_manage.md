# 部署 order_manage 云函数指南

## 问题描述
云函数出现 "Cannot find module 'wx-server-sdk'" 错误，需要重新部署。

## 解决方案

### 方法1：微信开发者工具（推荐）

1. **打开微信开发者工具**
2. **进入云开发控制台**：
   - 点击顶部工具栏的 "云开发" 按钮
   - 进入云函数管理页面
3. **重新部署云函数**：
   - 找到 `order_manage` 云函数
   - 右键点击 → 选择 "上传并部署：云端安装依赖"
   - 等待部署完成（显示绿色对勾）

### 方法2：命令行部署

```bash
# 进入云函数目录
cd cloudfunctions/order_manage

# 安装依赖
npm install

# 使用微信开发者工具的命令行工具部署
# (需要先安装微信开发者工具的CLI工具)
tcb functions deploy order_manage
```

### 验证部署

部署完成后，测试接取功能：
1. 进入小程序
2. 找到一个待接取的订单
3. 点击"接取订单"按钮
4. 应该显示"接单成功，你是接受者"

## 如果问题仍然存在

1. 删除云端现有的 `order_manage` 云函数
2. 重新创建并部署
3. 检查云环境ID是否正确：`cloud1-6gh7jgl8c5b16a83`

## 调试信息

云函数已经添加了详细的日志输出，可以通过云开发控制台查看执行日志。
